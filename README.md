## 🌐 How to Host on GitHub Pages (100% Free & Safe) / GitHub Pages Par Host Karne Ka Tareeka

Aap is portfolio ko **sirf 2 minutes me GitHub Pages** par bilkul free aur secure tareeke se live host kar sakte hain:

### Step 1: GitHub par New Repository Banayein
1. Apne GitHub account ([github.com](https://github.com)) par login karein.
2. Ek new repository create karein (e.g. `portfolio` ya `aayushpatidar1511.github.io`).
3. Repository ko **Public** rakhein.

### Step 2: Code ko GitHub par Push Karein
Apne terminal ya command prompt me `d:\portfolio` folder me jaakar yeh commands run karein:

```bash
git init
git add .
git commit -m "feat: Initial 3D Animated Developer Portfolio for Aayush Patidar"
git branch -M main
git remote add origin https://github.com/aayushpatidar1511/<YOUR-REPO-NAME>.git
git push -u origin main
```

### Step 3: GitHub Pages Enable Karein
1. Apne GitHub repository ke **Settings** tab me jayein.
2. Left sidebar me **Pages** par click karein.
3. **Build and deployment** section me:
   - **Source**: `Deploy from a branch` select karein (ya `GitHub Actions` select karein kyunki humne `.github/workflows/deploy.yml` pehle se bana di hai!).
   - Branch: `main` / `root (/)` select karein aur **Save** par click karein.
4. Kuch hi seconds me aapki portfolio live link generate ho jayegi:
   `https://aayushpatidar1511.github.io/<YOUR-REPO-NAME>/`
